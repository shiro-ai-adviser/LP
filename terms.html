利用規約

この規約は、SHIRO（以下「当方」といいます）が提供するBUYMA出品支援ツール「temaru」（以下「本サービス」といいます）の利用条件を定めるものです。お申し込みをもって、本規約に同意いただいたものとします。

第1条（本サービスの内容）

  1. 本サービスは、株式会社エニグモが運営する「BUYMA」への出品作業を、BUYMAが公式に提供する Personal Shopper API を通じて支援するツールです。
  2. 本サービスは当方が独自に提供するものであり、株式会社エニグモおよびBUYMAとは資本関係・提携関係のない、無関係の独立したサービスです。
  3. 本サービスの機能・画面・提供方法は、品質向上のため予告なく変更されることがあります。

第2条（アカウント）

  1. 登録時の情報は、正確な内容をご提供ください。
  2. ログイン情報（メールアドレス・パスワード・専用URL）は利用者ご自身で管理し、第三者に共有しないでください。共有によって生じた損害について、当方は責任を負いません。
  3. 1つのBUYMAアカウントにつき、登録できるのは1アカウントです。無料期間を繰り返し取得する目的での複数登録はできません。

第3条（BUYMAの利用規約の遵守）

  1. 利用者は、BUYMAの利用規約・ガイドライン・出品ルールを、利用者自身の責任で遵守してください。
  2. BUYMAのAPI利用申請・承認の取得および維持は、利用者の責任と負担で行うものとします。
  3. 本サービスは出品作業を支援するものであり、BUYMA上での販売行為の主体はあくまで利用者です。

第4条（出品内容についての責任）

  1. 本サービスを通じて出品する商品情報（商品名・説明文・価格・画像等）の内容および適法性については、利用者が全ての責任を負います。
  2. 画像・文章の取り込み機能は、利用者が権利者から利用を許諾されている素材、または利用者自身が権利を有する素材に限りご利用いただけます。第三者の著作権・商標権その他の権利を侵害する素材の取り込みには使用できません。
  3. AIによる自動入力（商品名・説明文・カテゴリ等）は入力の補助であり、出品前に利用者自身が内容を確認してください。生成された内容の正確性を当方は保証しません。

第5条（アカウント停止等についての免責）

  1. BUYMAによるアカウントの停止・制限・ペナルティ・強制解約その他の措置（以下「アカウント停止等」といいます）は、BUYMAと利用者との間の問題であり、当方はその責任を負いません。
  2. 本サービスはBUYMA公式APIのみを利用し、利用者のBUYMAパスワードを預からず、ブラウザの自動操作も行いません。ただし、これはアカウント停止等が生じないことを保証するものではありません。
  3. アカウント停止等により利用者に損害が生じた場合でも、当方の故意または重過失による場合を除き、当方は賠償の責任を負いません。

第6条（保証の否認）

  1. 本サービスは現状有姿で提供されます。売上・利益・出品数・BUYMA上の表示順位等について、当方は何らの保証もしません。
  2. BUYMA側の仕様変更・API停止・障害等により、本サービスの全部または一部が利用できなくなることがあります。

第7条（損害賠償の上限）

本サービスに関して当方が利用者に損害賠償責任を負う場合、その総額は、当該損害の発生時点から遡って直近3ヶ月間に利用者が当方に支払った利用料金の合計額を上限とします。ただし、当方の故意または重過失による場合はこの限りではありません。

第8条（料金・支払い）

  1. 利用料金は月額10,000円（税込）です。支払いはクレジットカード（決済代行：Stripe）によります。
  2. 無料お試し期間中は料金が発生せず、期間終了後も自動で課金されることはありません。継続する場合のみ、利用者自身のお手続きにより課金が開始されます。
  3. 支払い済みの料金は、日割り精算・返金を行いません。
  4. 支払いが確認できない場合、当方は本サービスの提供を停止できます。停止中も、出品済みの商品および入力済みのデータは削除されません。

第9条（解約）

  1. 利用者はいつでも解約できます。解約の連絡は、登録時のメールへの返信または当方への通知によります。
  2. 解約後、当月分の料金は返金されません。次回以降の課金は行われません。

第10条（データの取扱い）

  1. 当方は、本サービスの提供に必要な範囲で、利用者の登録情報・出品データ・受注の概要（受注ID・受注日・金額・ステータス等）を保存します。
  2. BUYMAのパスワードは一切預かりません。パスワードに代わり、利用者自身が承認したAPI接続を使用します。
  3. 受注に含まれる購入者の氏名・住所等の個人情報は、当方のサーバーに保存しません。
  4. 当方は、個別の利用者を特定できない形に加工した統計情報を、サービス改善のために利用できるものとします。

第11条（禁止事項）

次の行為を禁止します。該当した場合、当方は事前通知なく利用停止・登録抹消の措置をとることができます。

  • 法令または公序良俗に違反する行為、BUYMAの規約に違反する出品
  • 本サービスの逆コンパイル・リバースエンジニアリング・不正アクセス
  • 専用URL・ログイン情報の第三者への共有、アカウントの貸与・譲渡
  • 本サービスの提供を妨害する行為、サーバーに過度な負荷をかける行為
  • 反社会的勢力に該当する者、またはこれに準ずる者の利用

第12条（提供の中断・終了）

  1. 当方は、保守・障害対応等のため、本サービスの提供を一時中断することがあります。
  2. 当方は、30日前までに通知することにより、本サービスの提供を終了できます。この場合、終了日以降の期間に対応する支払い済み料金があるときは返金します。

第13条（規約の変更）

当方は、必要に応じて本規約を変更できます。重要な変更を行う場合は、本サービスの画面またはメールで事前にお知らせします。変更後に本サービスの利用を継続した場合、変更後の規約に同意したものとみなします。

第14条（準拠法・管轄）

本規約は日本法に準拠します。本サービスに関して紛争が生じた場合、当方の所在地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。
