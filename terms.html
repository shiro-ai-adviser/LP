利用規約

この規約は、SHIRO（以下「当方」といいます）が提供するBUYMA出品支援ツール「temaru」（以下「本サービス」といいます）の利用条件を定めるものです。お申し込みをもって、本規約に同意いただいたものとします。

第1条（本サービスの内容）

  1. 本サービスは、株式会社エニグモが運営する「BUYMA」への出品作業を、BUYMAが公式に提供する Personal Shopper API を通じて支援するツールです。
  2. 利用者が申し込んだ場合、オプションとして、Amazon.co.jp への出品と、BUYMAとAmazonの間の在庫の連動（以下「Amazon連携」といいます）を、Amazonが公式に提供する Selling Partner API を通じて提供します。
  3. 本サービスは当方が独自に提供するものであり、株式会社エニグモおよびBUYMA、ならびにAmazon.com, Inc.およびその関連会社とは資本関係・提携関係のない、無関係の独立したサービスです。これらの会社が本サービスを推奨・保証するものではありません。
  4. 本サービスの機能・画面・提供方法は、品質向上のため予告なく変更されることがあります。

第2条（アカウント）

  1. 登録時の情報は、正確な内容をご提供ください。
  2. ログイン情報（メールアドレス・パスワード・専用URL）は利用者ご自身で管理し、第三者に共有しないでください。共有によって生じた損害について、当方は責任を負いません。
  3. 1つのBUYMAアカウントにつき、登録できるのは1アカウントです。無料期間を繰り返し取得する目的での複数登録はできません。

第3条（BUYMAの利用規約の遵守）

  1. 利用者は、BUYMAの利用規約・ガイドライン・出品ルールを、利用者自身の責任で遵守してください。
  2. BUYMAのAPI利用申請・承認の取得および維持は、利用者の責任と負担で行うものとします。
  3. 本サービスは出品作業を支援するものであり、BUYMA上での販売行為の主体はあくまで利用者です。

第4条（出品内容についての責任）

  1. 本サービスを通じて出品する商品情報（商品名・説明文・価格・画像等）の内容および適法性については、利用者が全ての責任を負います。
  2. 画像・文章の取り込み機能は、利用者が権利者から利用を許諾されている素材、または利用者自身が権利を有する素材に限りご利用いただけます。第三者の著作権・商標権その他の権利を侵害する素材の取り込みには使用できません。
  3. AIによる自動入力（商品名・説明文・カテゴリ等）は入力の補助であり、出品前に利用者自身が内容を確認してください。生成された内容の正確性を当方は保証しません。

第5条（アカウント停止等についての免責）

  1. BUYMAによるアカウントの停止・制限・ペナルティ・強制解約その他の措置（以下「アカウント停止等」といいます）は、BUYMAと利用者との間の問題であり、当方はその責任を負いません。
  2. 本サービスはBUYMA公式APIのみを利用し、利用者のBUYMAパスワードを預からず、ブラウザの自動操作も行いません。ただし、これはアカウント停止等が生じないことを保証するものではありません。
  3. アカウント停止等により利用者に損害が生じた場合でも、当方の故意または重過失による場合を除き、当方は賠償の責任を負いません。

第6条（Amazon連携）

  1. Amazon連携は、利用者自身がAmazonの承認画面で許可した範囲でのみ、利用者のAmazon出品用アカウントにアクセスします。利用者は、この許可をAmazonのセラーセントラルからいつでも取り消すことができます。
  2. Amazon上での販売行為の主体はあくまで利用者です。利用者は、Amazonの出品規約・ポリシー（出品にカテゴリーやブランドの承認が必要な商品の扱い、偽造品の禁止、ドロップシッピング（仕入れ先から購入者へ直接発送すること）の制限、出荷作業日数等を含みます）を、利用者自身の責任で遵守してください。出品の可否、承認の取得、商品の真贋、仕入れと発送の方法は利用者が判断するものであり、当方はこれらを確認・保証しません。
  3. 在庫の連動は、BUYMAとAmazonからの通知と、定期的な確認によって行います。連動は即時でも確実でもありません。各販売先での反映の遅れ、通知の遅延や欠落、障害、仕様変更等により、連動が遅れる、または行われないことがあり、同じ商品が両方で売れること（二重販売）を完全には防げません。
  4. 利用者は、在庫の連動だけに頼らず、出荷作業日数に余裕を持たせる、売り切れた商品を自ら取り下げる、在庫を自ら確認する等、二重販売が起きても対応できる運用を行ってください。
  5. 二重販売その他の理由による注文のキャンセル、キャンセル率の上昇、出品の停止、アカウントの評価の低下、売上金の保留、アカウントの停止その他Amazonによる措置は、Amazonと利用者との間の問題であり、当方の故意または重過失による場合を除き、当方はその責任を負いません。
  6. Amazon連携の料金とお試し期間は、申込み時に本サービスの画面で表示するものとします。本サービス本体の提供が停止または解約されたときは、Amazon連携も停止します。
  7. 当方は、利用者のAmazonでの販売がAmazonの規約に違反している疑いがあるときは、Amazon連携を停止することができます。また、当方がAmazonとの間で負う義務を果たすために必要な範囲で、その旨をAmazonに報告することがあります。

第7条（保証の否認）

  1. 本サービスは現状有姿で提供されます。売上・利益・出品数・BUYMAやAmazon上の表示順位等について、当方は何らの保証もしません。
  2. BUYMAまたはAmazon側の仕様変更・API停止・障害、または各社の判断等により、本サービスの全部または一部が利用できなくなることがあります。
  3. 在庫アラートは、利用者が登録した仕入先のページを定期的に確認し、在庫切れの可能性をお知らせする参考情報です。仕入先サイトの作りやアクセス制限により確認できないサイトがあり、在庫切れを見逃すこと、在庫があるのにお知らせすることがあります。在庫の最終的な確認と、出品の取り下げ等の対応は利用者が行ってください。

第8条（損害賠償の上限）

本サービスに関して当方が利用者に損害賠償責任を負う場合、その総額は、当該損害の発生時点から遡って直近3ヶ月間に利用者が当方に支払った利用料金の合計額を上限とします。ただし、当方の故意または重過失による場合はこの限りではありません。

第9条（料金・支払い）

  1. 利用料金は月額25,000円（税込）です。ただし、改定前にご利用開始の方の料金は従前のとおりとし、当方が定める特別入会（招待経由のお申し込み）の方は月額12,000円（税込）です。支払いはクレジットカード（決済代行：Stripe）によります。
  2. 無料お試し期間中は料金が発生せず、期間終了後も自動で課金されることはありません。継続する場合のみ、利用者自身のお手続きにより課金が開始されます。
  3. 支払い済みの料金は、日割り精算・返金を行いません。
  4. 支払いが確認できない場合、当方は本サービスの提供を停止できます。停止中も、出品済みの商品および入力済みのデータは削除されません。

第10条（解約）

  1. 利用者はいつでも解約できます。解約の連絡は、登録時のメールへの返信または当方への通知によります。
  2. 解約後、当月分の料金は返金されません。次回以降の課金は行われません。

第11条（データの取扱い）

  1. 当方は、本サービスの提供に必要な範囲で、利用者の登録情報・出品データ・受注の概要（受注ID・受注日・金額・ステータス等）を保存します。
  2. BUYMAのパスワードは一切預かりません。パスワードに代わり、利用者自身が承認したAPI接続を使用します。
  3. 受注に含まれる購入者の氏名・住所等の個人情報は、当方のサーバーに保存しません。
  4. 当方は、BUYMAからの通知により、BUYMA上の商品の内容（商品名・説明・価格・画像の情報等）を受け取り、本サービスへの反映のために保存します。BUYMAの画面で直接作成・編集した商品の内容も含みます。
  5. BUYMA側で変更された商品名・説明・価格は、BUYMAからの通知を受けて本サービスに反映されます。通知は数分から数時間（まれに半日近く）遅れることがあり、反映の時刻は保証しません。本サービスに未送信の編集がある商品は自動では書き換えず、利用者が反映するか維持するかを選びます。画像は反映されません。
  6. Amazon連携では、出品情報（SKU・ASIN等）、在庫数、注文の番号・日時・商品・数量を取得し、在庫の連動と出品のためにのみ使用します。購入者の氏名・住所・電話番号・メールアドレスは取得しません。Amazonへの接続に使う認証情報は当方が管理するサーバー内にのみ保管し、利用者が本サービスの画面で接続を解除したときに削除します。取得した情報を第三者に提供・販売することはありません。
  7. 当方は、本サービスで保管する情報について不正アクセス・漏えい等を知ったときは、速やかに利用者に通知します。また、必要に応じて株式会社エニグモおよびAmazonに報告します。
  8. 当方は、個別の利用者を特定できない形に加工した統計情報を、サービス改善のために利用できるものとします。
  9. 本サービスの紹介サイト（temaru.shiro-hq.com）では、閲覧状況を把握するために Google アナリティクスを使用しています。Cookie 等を通じて閲覧情報が Google に送信されますが、氏名やメールアドレスなど個人を特定する情報は含みません。
  10. 取り込み機能（取り込みボタン・Chrome拡張機能の両方を含みます）は、利用者が操作した仕入先ページの内容（商品情報・ページ内の文字・商品画像のURLと縮小版）を、利用者のブラウザから当方サーバーへ送信します。送信された内容は、取り込みの候補（ブランド・色・サイズ・カテゴリ等）と商品名・商品説明の作成にのみ使用し、その処理のために当方が利用するAIサービス（Google LLC の Gemini API ほか）へ送信します。利用者が取り込みを確定しないまま10分が経過した内容は、自動的に消去されます。Chrome拡張機能では、利用者が許可したウェブサイトについて、ページを移動するたびにこの読み取りを自動的に行うことがあります。この許可は、拡張機能の設定からいつでも取り消せます。拡張機能の取扱いの詳細はプライバシーポリシーをご覧ください。
